Toolset Network Monitor

Uma suíte completa de ferramentas em Python para monitoramento e diagnóstico avançado de redes Wi-Fi e locais.

## 🛠️ Ferramentas Inclusas:
1. **Monitor Wi-Fi**: Grava logs de tráfego e sinal (dBm) em tempo real.
2. **Gerador de Gráficos**: Plota a qualidade do sinal e velocidade da rede.
3. **Radar (Site Survey)**: Mapeia roteadores vizinhos e sugere o melhor canal.
4. **Scanner de Rede Local**: Usa UDP Forcing para achar dispositivos ocultos.
5. **Espião de Processos**: Mostra quais apps estão consumindo internet.
6. **Auditor de Hosts**: Verifica domínios bloqueados no Windows.
7. **Canivete Suíço**: Faz testes de Ping, DNS Público e Traceroute.

## ⚙️ Como usar:
Instale as dependências com `pip install -r requirements.txt` e execute o `menu_principal.py`.
